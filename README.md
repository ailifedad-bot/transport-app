# بازار حمل — نسخه آزمایشی

## اجرای نسخه آزمایشی
این نسخه یک نمونه تک‌فایلی HTML است و برای آزمایش اولیه در مرورگر ساخته شده است.

1. در GitHub شاخه `repair/market-hamal-demo` را باز کنید.
2. فایل `index.html` را انتخاب و محتوای آن را بررسی کنید.
3. برای اجرای آنلاین، در تنظیمات مخزن به **Settings → Pages** بروید.
4. در بخش **Build and deployment** گزینه **Deploy from a branch** را انتخاب کنید.
5. شاخه `repair/market-hamal-demo` و پوشه `/ (root)` را انتخاب و Save کنید.
6. پس از انتشار، نشانی Pages نمایش داده‌شده را با Chrome اندروید باز کنید.

## داده‌های آزمایشی
- فروشگاه: `ST-1001` با اشتراک فعال آزمایشی
- مشتری: `CU-1001` با اشتراک فعال آزمایشی
- اعتبار خرید اولیه مشتری: 500,000 تومان

## مسیر سفارش
ثبت سفارش ← تأیید فروشگاه و کسر مبلغ کالا از کیف اعتبار ← تعیین حمل‌کننده ← دریافت کالا از فروشگاه ← ارسال کالا ← تحویل به مشتری ← انتخاب مرجوعی بله/خیر ← بستن فرایند و گزارش فروشگاه.

تأیید مشتری به‌عنوان یک مرحله مستقل در گردش کار وجود ندارد.

## تفکیک مالی
- کیف اعتبار مشتری فقط برای مبلغ کالا در فروشگاه عضو استفاده می‌شود.
- مبلغ کالا پس از تأیید فروشگاه از کیف اعتبار خرید کسر می‌شود.
- هزینه حمل جداگانه نمایش داده می‌شود و از کیف اعتبار خرید کسر نمی‌شود.
- اشتراک فروشگاه و اشتراک مشتری مستقل از کیف اعتبار و هزینه حمل هستند.

## سناریوهای آزمون دستی
1. با داده اولیه یک سفارش 250,000 تومانی و هزینه حمل 50,000 تومانی ثبت کنید.
2. قبل از تأیید فروشگاه، موجودی کیف اعتبار باید 500,000 تومان بماند.
3. «تأیید فروشگاه» را بزنید؛ موجودی باید به 250,000 تومان کاهش یابد، نه 200,000 تومان.
4. مراحل تعیین حمل‌کننده، دریافت، ارسال و تحویل را به ترتیب انجام دهید.
5. گزینه «عدم مرجوعی» را انتخاب کنید؛ سفارش باید تکمیل و در گزارش فروشگاه ثبت شود.
6. سفارش دوم بسازید و گزینه مرجوعی را انتخاب کنید؛ گزارش مرجوعی باید برای فروشگاه قابل مشاهده باشد.
7. با تاریخ اشتراک منقضی، ثبت سفارش باید متوقف شود.
8. با اعتبار کمتر از مبلغ کالا، تأیید فروشگاه باید متوقف شود.
9. کد مشتری دیگری را در کیف اعتبار انتخاب کنید؛ گردش اعتبار باید فقط برای همان کد نمایش داده شود.

## محدودیت‌های مهم
- داده‌ها فقط در حافظه محلی همان مرورگر و دستگاه ذخیره می‌شوند؛ پاک‌کردن داده‌های مرورگر آن‌ها را حذف می‌کند.
- این نسخه ورود امن، چندکاربره‌سازی، پایگاه داده، API، درگاه پرداخت، اعتبارسنجی واقعی کد شارژ، اعلان و ارسال گزارش واقعی ندارد.
- شارژ کیف اعتبار در این نسخه نمایشی است و نباید برای تراکنش واقعی استفاده شود.
- این نمونه برای ارزیابی منطق اولیه است، نه بهره‌برداری تجاری.
